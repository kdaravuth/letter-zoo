# Proposal: 008-geometry-drawing-game

**Interactive SVG Math Drawing Primitive (`geometry-draw`), Drawing Lesson (`g05`) & Play Studio Drawing Game**

- **From**: 8 interactive SVG primitives without freehand/geoboard shape drawing or mirror-symmetry painting.
- **To**: A 9th Safari-safe decoupled primitive (`geometry-draw`) supporting geoboard dot-connect polygon drawing (`triangle`, `square`, `rectangle`), mirror-symmetry grid painting, and target-area grid painting; a new 4-step Khmer Geometry Drawing lesson (`g05-drawing-shapes-and-symmetry.json`) with pre-generated Khmer MP3 audio; and a 5th **គូររូបគណិត (Math Drawing Studio)** game tab inside `/play`.
- **Reason**: Gives children aged 6–12 joyful, creative hands-on drawing while building authentic geometric intuition (sides, right angles, symmetry, and area) under strict WCAG 2.2 AA and Safari SVG guardrails.
- **Impact**: Extends `activity-engine-primitives` and `joyful-play-and-garden` capabilities cleanly without breaking existing lessons.
